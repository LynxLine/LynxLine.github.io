Claude Code 用スキル「i-have-adhd」

2026年9月2日

  • AI
  • Claude
  • Tools

この記事を読む： English 한국어

AI アシスタントには共通の癖があります。聞いたことに答える前に、三段落ぶんの前置きが入るのです。「調べてみますね……ついでに触れておくと……見つかった内容をまとめると……」。肝心の答えが出てくる頃には、何を聞いたのか忘れています。

ayghri/i-have-adhd は、この振る舞いをオフにする Claude Code のスキルです。有効にすると、モデルの話し方がこう変わります。

  • 答え、または次にやることが必ず最初に来る
  • 複数ステップの作業は番号付きで、1 ステップにつき 1 つの具体的な行動
  • 前置き、振り返り、締めのまとめはなし
  • 進捗はターンをまたいで引き継がれ、毎回リセットされない
  • 所要時間は「すぐに」「まもなく」ではなく具体的に示す

もともとは ADHD のアクセシビリティ向けに作られたものですが、要点を埋もれさせないツールが欲しいだけの人たちにも広まり、インストール数は数千に達しています。結局、冗長な文章を読み進められる我慢の限界は、誰でも似たようなものなのでしょう。

インストールはコマンド 2 つです。

claude plugin marketplace add ayghri/i-have-adhd
claude plugin install i-have-adhd@i-have-adhd

あとはセッションごとに一度 /i-have-adhd を実行すれば、その会話の間ずっと有効になります。
