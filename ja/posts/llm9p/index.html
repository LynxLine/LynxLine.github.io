llm9p：9P プロトコル越しに LLM を使う

2026年9月3日

  • Inferno OS
  • AI
  • Claude

この記事を読む： English

このブログではかつて、Inferno OS を Raspberry Pi に移植する長いラボ連載を書きました。それから何年も経った今、同じ「すべてはファイルである」という思想を言語モデルに持ち込んだ人が現れました。llm9p は LLM を 9P ファイルシステムとして公開します。ask にプロンプトを書き込み、応答を読み出す。それだけです。モデル名、temperature、システムプロンプトもすべてファイルで、会話の状態はリセットするまで保持されます。

Plan 9 らしさが本物なのはマウント方法です。plan9port の 9pfuse、Linux カーネル標準の 9P モジュール、そして何より嬉しいのが、ホスト型 Inferno OS である Infernode。SDK も API クライアントも要りません。ファイルとパイプだけで済みます。

バックエンドは差し替え可能で（現在は Anthropic API、Claude Code CLI と Ollama は対応予定）、応答は stream/ ディレクトリを通じて逐次ストリーミングされます。
