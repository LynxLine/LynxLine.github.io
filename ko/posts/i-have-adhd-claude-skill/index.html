Claude Code용 i-have-adhd 스킬

2026년 9월 2일

  • AI
  • Claude
  • Tools

다른 언어로 읽기: English 日本語

모든 AI 어시스턴트에게는 똑같은 버릇이 있습니다. 정작 물어본 것을 답하기 전에 세 단락쯤 목을 가다듬는 겁니다. “한번 살펴볼게요… 참고로 말씀드리면… 찾은 내용을 정리하면…” 답이 나올 때쯤이면 이미 무엇을 물었는지 잊어버린 뒤입니다.

ayghri/i-have-adhd는 이런 행동을 그냥 꺼버리는 Claude Code 스킬입니다. 활성화하면 모델이 말하는 방식이 이렇게 바뀝니다.

  • 답 또는 다음 행동이 항상 맨 먼저 나온다
  • 여러 단계로 된 작업은 번호를 매기고, 한 단계에 하나의 구체적 행동만 담는다
  • 서두도, 요약 반복도, 마무리 정리도 없다
  • 진행 상황은 매번 초기화되지 않고 턴을 넘어 이어진다
  • 소요 시간은 “곧"이나 “머지않아"가 아니라 구체적으로 제시한다

원래는 ADHD 접근성을 위해 만들어졌지만, 핵심을 묻어버리지 않는 도구를 원하는 사람들 사이에서 수천 건의 설치 수를 기록했습니다. 알고 보면 쓸데없는 말을 헤치고 읽어내는 인내심의 한계는 다들 비슷한 모양입니다.

설치는 명령어 두 개면 끝입니다.

claude plugin marketplace add ayghri/i-have-adhd
claude plugin install i-have-adhd@i-have-adhd

그다음 세션마다 한 번 /i-have-adhd를 실행하면, 그 대화가 끝날 때까지 계속 적용됩니다.
