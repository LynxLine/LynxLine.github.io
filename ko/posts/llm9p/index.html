llm9p: 9P 프로토콜 위의 LLM

2026년 9월 3일

  • Inferno OS
  • AI
  • Claude

다른 언어로 읽기: English 日本語 Русский

이 블로그가 Inferno OS를 Raspberry Pi로 포팅하는 랩 연재를 통째로 다룬 지 몇 년이 지난 지금, 누군가 같은 “모든 것은 파일이다"라는 철학을 언어 모델에 그대로 적용했습니다. llm9p는 LLM을 9P 파일시스템으로 노출시킵니다. ask에 프롬프트를 쓰고, 응답을 읽어오면 됩니다. 모델, temperature, 시스템 프롬프트도 전부 파일이고, 대화 상태는 리셋하기 전까지 유지됩니다.

진짜 Plan 9다운 지점은 마운트 방식입니다. plan9port의 9pfuse, 리눅스 기본 9P 커널 모듈, 그리고 무엇보다도 호스팅형 Inferno OS인 Infernode를 통해 마운트할 수 있습니다. SDK도, API 클라이언트도 필요 없습니다. 파일과 파이프만 있으면 됩니다.

백엔드는 교체 가능하며(현재는 Anthropic API, Claude Code CLI와 Ollama는 예정), 응답은 stream/ 디렉터리를 통해 점진적으로 스트리밍됩니다.
