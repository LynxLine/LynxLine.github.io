TogMeg

June 15, 2011

  • Mac
  • TTS
  • Language Learning

TogMeg is a small Mac app for learning vocabulary in a new language: it shows you a word, makes you type the correct spelling, and speaks it using the system’s TTS voices so you get pronunciation along with spelling in the same pass. On Lion that’s up to 24 languages built in; on older OS X, Infovox iVox voices fill the gap for about $99 each (with a month-long demo, plenty to see if TogMeg is worth it for you).

Repeating a word while typing it and hearing it seems to actually stick better than just reading a list — building it to test that idea.
