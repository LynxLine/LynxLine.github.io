Скилл i-have-adhd для Claude Code

02.09.2026

  • AI
  • Claude
  • Tools

Читать на другом языке: English 日本語 한국어

У каждого AI-ассистента одна и та же привычка: три абзаца прочисток горла, прежде чем он скажет то, о чём вы на самом деле спросили. «Сейчас разберусь… кстати, стоит упомянуть… вот итог того, что удалось найти…» К моменту, когда появляется ответ, вы уже забыли, о чём спрашивали.

ayghri/i-have-adhd — скилл для Claude Code, который просто отключает это поведение. Когда он активен, модель начинает говорить иначе:

  • Ответ или следующее действие — всегда первым делом
  • Многошаговая работа нумеруется, на каждом шаге — одно конкретное действие
  • Без вступлений, без повторов, без итоговой сводки в конце
  • Прогресс переносится между репликами, а не сбрасывается каждый раз
  • Оценки по времени конкретны, а не «скоро» или «в ближайшее время»

Скилл делали для доступности при СДВГ, но его тысячи раз установили люди, которым просто хочется инструментов, не прячущих суть под водой. Оказывается, порог терпения продираться сквозь воду у большинства из нас примерно одинаковый.

Установка — две команды:

claude plugin marketplace add ayghri/i-have-adhd
claude plugin install i-have-adhd@i-have-adhd

Затем один раз за сессию выполните /i-have-adhd — и это останется включённым до конца разговора.
