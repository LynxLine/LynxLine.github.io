llm9p: LLM поверх протокола 9P

03.09.2026

  • Inferno OS
  • AI
  • Claude

Читать на другом языке: English 日本語 한국어

Спустя годы после того, как этот блог посвятил целую серию лабораторных работ портированию Inferno OS на Raspberry Pi, кто-то применил ту же философию «всё — это файл» к языковым моделям. llm9p представляет LLM в виде файловой системы 9P: пишете промпт в ask, читаете ответ обратно. Модель, temperature и системный промпт — тоже просто файлы, а состояние диалога сохраняется до сброса.

По-настоящему в духе Plan 9 то, как это монтируется: через 9pfuse из plan9port, через встроенный в Linux модуль ядра 9P или — лучше всего — через Infernode, хостинговую Inferno OS. Никакого SDK, никакого API-клиента — только файлы и пайпы.

Бэкенды подключаемые (сейчас — API Anthropic, Claude Code CLI, в планах Ollama), а ответы стримятся постепенно через директорию stream/.
